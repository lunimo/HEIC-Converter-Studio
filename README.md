# 🖼️ HEIC Converter Studio

> Современный, высокопроизводительный конвертер файлов HEIC в JPG/PNG для Windows 11 с поддержкой контекстного меню и автоматическими обновлениями.

---

## ✨ Основные возможности

* 🚀 **Высокая скорость работы**: Моментальный запуск и пакетная конвертация изображений без задержек.
* 🎨 **Fluent Design**: Современный интерфейс в стиле Windows 11 с поддержкой тёмной/светлой темы.
* 🖱️ **Интеграция с Проводником**: Быстрая конвертация прямо из контекстного меню (ПКМ) по файлам `.heic`.
* 🔄 **Автообновления**: Встроенная проверка релизов через GitHub API с удобным уведомлением.
* 📦 **Портативность**: Доступен как в виде инсталлятора, так и в виде портативного ZIP-архива.
