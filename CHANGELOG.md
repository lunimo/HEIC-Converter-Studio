### **История изменений (Changelog)**

###### Версия 1.0.0 (Базовый релиз)

1. Разработан базовый графический интерфейс на PySide6 (Qt).
2. Реализована основная функция конвертации файлов .heic в форматы JPEG и PNG с помощью библиотека Pillow и pillow-heif.
3. Добавлена возможность выбора папки для сохранения результатов.



###### Версия 1.1.0 (Производительность и EXIF)

1. Добавлена многопоточность (обработка файлов в отдельных потоках), благодаря чему интерфейс больше не «зависает» при конвертации больших папок.
2. Реализован полный перенос EXIF-метаданных (дата съёмки, геолокация GPS, параметры камеры) из исходных файлов HEIC в итоговые JPEG/PNG.
3. Добавлена функция выбора качества сжатия для JPEG.



###### Версия 1.2.0 (Удобство использования / UX)

1. Добавлена поддержка Drag-and-Drop — файлы и папки можно просто перетаскивать в окно программы.
2. Реализовано автоматическое сохранение настроек пользователя (выбранный формат, качество, пути) между запусками программы.
3. Добавлено опциональное удаление исходных HEIC-файлов после успешной конвертации.



###### Версия 1.3.0 (Интеграция с системой)

1. Добавлена интеграция в контекстное меню Windows (запуск конвертации по правому клику мыши на файл .heic или папку).
2. Добавлена обработка аргументов командной строки при запуске программы.



###### Версия 2.0.0 (Автономная сборка и полноценный инсталлятор)

1. Осуществлён переход на однофайловую сборку PyInstaller (--onefile) — программа запакована в один монолитный .exe.
2. Создан полноценный мастер установки (Inno Setup Installer):
3. Создание ярлыков на Рабочем столе и в меню «Пуск».
4. Автоматическая прописка ключей в реестре Windows.
5. Функция корректного закрытия запущенных процессов при обновлении.
6. Полноценный деинсталлятор с возможностью очистки пользовательских настроек.
